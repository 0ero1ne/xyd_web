# XYD_web

## 项目介绍

XYD_web 是一个基于 uni-app 开发的农户植保服务微信小程序前端项目，主要面向农户用户提供植保作业服务入口。用户可通过微信头像昵称完成登录，进入平台后查看服务信息、发布作业需求、查看订单状态以及管理个人资料。

本项目作为微信小程序前端，主要负责页面展示、用户交互、微信登录、接口请求和本地缓存管理；后端服务由 Spring Boot 提供接口支持，数据库采用 PostgreSQL 存储用户信息、登录日志及后续业务数据。

## 项目功能

目前已实现或规划的主要功能包括：

1. 微信小程序头像昵称登录
2. 登录后用户信息展示
3. 个人中心页面
4. 退出登录与本地缓存清理
5. 对接后端登录接口
6. 保存后端返回的 token 和 userInfo
7. 后续扩展：发布植保作业订单
8. 后续扩展：查询我的订单
9. 后续扩展：查看订单详情
10. 后续扩展：服务记录与平台信息展示
